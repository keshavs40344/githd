## ⚡ Key Engineering Innovations

### 1. 🎛️ Inharmonic Bronze Bell Acoustic Synthesis (WebAudio DSP)
Unlike basic recorded audio files that suffer from latency, bandwidth spikes, and clipping, **Dharma.OS synthesizes authentic bronze temple bell acoustics in real-time** via the browser's WebAudio API:
- **9-Partial Inharmonic Spectrum**: Combines prime frequencies `[216Hz, 432Hz, 518Hz, 648Hz, 864Hz, 1180Hz, 1512Hz, 2160Hz, 2880Hz]` with micro-detuning `(±3Hz)` to reproduce physical metal resonance.
- **Clapper Impact Transient**: High-frequency triangle wave decay (1400Hz → 300Hz in 35ms) simulating physical bronze hammer strike.
- **Dynamic Decay Envelope**: 5.5-second exponential energy decay with synthetic reverberant delay line.
- **iOS/Android Autoplay Policy Bypass**: State machine that automatically tracks and resumes suspended `AudioContext` instances on initial user touch events.

### 2. 🧠 Psychologist-Grade Krishna AI (CBT + Vedanta Engine)
A structured 5-tier cognitive therapy pipeline combining modern clinical psychology with Vedic epistemology:
- **Radical Empathy Layer**: Immediate non-judgmental validation of psychological distress.
- **Subconscious Telemetry**: Analyzes *Guna* balance (*Sattva/Rajas/Tamas*) and identifies cognitive distortions (Catastrophizing, Outcome-Attachment / फलासक्ति, Ego-Defense).
- **Intimate Divine Guidance**: Personalized counsel delivered in Sri Krishna's authentic voice.
- **Precision Shloka Prescription**: Direct mapping to exact chapter and verse with Devanagari, transliteration, and practical modern context.
- **24-Hour Behavioral Action Plan**: Step-by-step CBT somatic grounding exercises (*5-4-3-2-1 Grounding*, *Circle of Control*, *Behavioral Activation*) with vocal speech synthesis.

### 3. 📜 Anvaya Sanskrit AST Tokenizer & 700 Shloka Engine
- **Word-Level Morphological Breakdown**: Every single word across all 700 verses is tokenized into its verbal root (*Dhātu*), grammatical case (*Vibhakti*), and multi-lingual semantics.
- **Karaoke Highlighting**: Word-by-word synchronized visual glow tracking Sanskrit recitation timing.
- **Multi-Tradition Exegesis**: Simultaneous side-by-side view of 7 classical commentaries:
  - *Adi Shankaracharya* (Advaita Vedanta)
  - *Ramanujacharya* (Vishishtadvaita)
  - *Madhvacharya* (Dvaita)
  - *Sant Jnaneshwar* (Jnaneshwari)
  - *Swami Vivekananda* (Practical Vedanta)
  - *Quantum Consciousness & Modern Science*

### 4. 🛕 Real-Time Virtual Temple Sanctum
- **Interactive Pushpanjali**: Lightweight particle physics calculating velocity, gravity, rotational inertia, and drag for falling floral petals (*Lotus, Rose, Tulsi*).
- **Virtual Aarti Thali**: 360-degree cyclical angular rotation with dynamic multi-layer flame flickering shaders and synchronized shankhnaad.

## 🚀 Local Development Setup

```bash
# 1. Clone the repository
git clone https://github.com/keshavs40344/githd.git
cd githd

# 2. Install dependencies (Clean tree, zero vulnerabilities)
npm install

# 3. Launch local dev environment
npm run dev

# 4. Compile optimized production build
npm run build
```
